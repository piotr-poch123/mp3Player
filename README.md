Spotify Desktop Controller

A desktop application built with Electron and JavaScript that connects to Spotify and displays the user's current playback information. The app uses Spotify's Web API and OAuth 2.0 with PKCE to authenticate users and interact with their playback.

## Features
- Spotify account authentication using OAuth 2.0 with PKCE
- Displays the currently playing song
- Updates playback information periodically
- Playback controls, including play, pause, skip, and rewind
- Volume adjustment through Spotify's Web API

## Technologies
- JavaScript
- Electron
- Node.js
- Express
- Spotify Web API
- HTML and CSS

## Purpose
Built to practice desktop application development, API integration, OAuth authentication, and communication between Electron's main and renderer processes.
